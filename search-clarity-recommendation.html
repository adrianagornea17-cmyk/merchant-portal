✓ Section labels are now bold black, plain case, no "›" — reads as an inert group header, matching the app's existing nav flyout.
✓ Result rows use the same amber accent already used for links elsewhere in the app — the affordance is visible immediately, not just on hover.

Rule of thumb applied — matches the app's nav flyout

  • Bold black, plain case, no hover — category / section label (not interactive).
  • Amber text, always-on — clickable result row; color itself signals "link," no hover needed to discover it.
  • Gray background + black text on hover/focus — indicates the currently focused row, same pattern as the Transactions & Reports flyout menu.
